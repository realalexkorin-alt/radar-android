# 0.1.32 · динамика надбавки

Переключатель «Прогнозирование» по умолчанию выключен. На сохранённых точках стрелка сравнивает два последних успешных измерения: зелёная вверх/красная вниз, равенство или первое измерение — серый штрих. 0% — заглушка до накопления истории, не рассчитанная вероятность. Размер плашки сохраняется; под индикатор резервируется правая часть. Ошибки/дубли/старые ответы не меняют направление.

У пользователей одна строка: онлайн — возраст координат, офлайн — последнее посещение; аналогично в друзьях. Возраст сохранённых точек остаётся отдельной настройкой.

Проверка: TrendTest на API35 — рост, падение до нуля, отсутствие значения, равенство, старый ответ, независимость точек и сохранение состояния. Release и lint.
