## Границы

Полевая проверка на двух физических телефонах с реальным движением GPS пока не выполнена; серверные клиенты используют синтетические координаты, Android-проверки — эмуляторы. Расчётная надбавка RUB не считается подтверждённым точным совпадением с Яндекс Про. При отсутствии RUB нет подстановки множителя. Сервер выдаёт максимум 200 точек среди 1000 последних активных установок; перед большим запуском нужен пространственный индекс. У Neon есть отдельное хранение резервных версий, поэтому удаление из рабочей таблицы не означает уничтожения инфраструктурных recovery-версий.
