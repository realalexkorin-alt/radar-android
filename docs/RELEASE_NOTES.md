Радар 0.1.5-alpha — тест обновления поверх установленной 0.1.4-alpha.

Автоматическая проверка наличия новой версии при холодном запуске (без навязчивых сообщений при отсутствии обновления). В настройках доступна ручная проверка. Загрузка и установка через GitHub Releases с проверкой SHA-256, подписи APK и увеличения versionCode сохранены.

Регрессионный тест действительного опубликованного APK проверяет его размер, SHA-256, ZIP-структуру, AndroidManifest.xml, classes.dex и чтение Android PackageManager, включая Android 15.

Android package: dev.raf.radar; versionCode: 6. Для обновления должна использоваться та же подпись, что и в релизе 0.1.4. Существующее приложение не удалять, данные сохраняются при установке поверх.

Первое обновление на устройстве с 0.1.4 инициируется вручную: Настройки → Проверить обновления, поскольку автоматическая проверка впервые добавлена в 0.1.5. Новый трёхвкладочный интерфейс пока не включён в этот технический патч.
