Радар 0.1.4-alpha — обновления из приложения и проверка разрешений.

Канал обновлений закреплён за realalexkorin-alt/radar-android: вводить адрес больше не нужно. Проверка версии перед загрузкой, прогресс скачивания, проверка SHA-256, имени пакета и постоянной подписи. После выдачи разрешения на установку скачанный APK используется повторно.

При входе приложение проверяет точную геопозицию, уведомления, показ поверх других приложений и установку обновлений. Системные разрешения запрашиваются последовательно. После отказа приложение объясняет, какой доступ отсутствует; при следующем входе проверяет снова. Если Android запретил повторный системный запрос, открывается соответствующий экран настроек. Мониторинг запускается только с геопозицией и уведомлениями. Лишние разрешения не добавлены.

Виджет: название точки, названия тарифов и суммы, крестик справа вверху. Убраны нижняя подпись, ряд кнопок и сворачивание. Нажатие открывает приложение; удержание без движения — настройки после отпускания; удержание с движением — перенос виджета. Положение сохраняется. Устаревшие суммы приглушаются.

Моя геопозиция получает приоритет в общей очереди. Другие точки запрашиваются при открытой карте со списком, если показаны в виджете или для них включены уведомления. При уходе с экрана ненужные фоновые запросы прекращаются. Уведомления и пауза при ограничениях сервиса сохранены; общий интервал между обновлениями точек — не менее 15 секунд.

Обновление: Настройки → Проверить обновления. Репозиторий realalexkorin-alt/radar-android. Установка поверх предыдущей версии; постоянная подпись и сохранённые настройки.

Надбавки в рублях остаются расчётными; сравнение с Яндекс Про требуется отдельно.
