Радар 0.1.1-alpha. Карта, сохранённые точки, динамическая геопозиция, настраиваемый виджет. После визуальной проверки добавлены состояние загрузки карты, тень текста виджета и пересоздание его окна при смене масштаба.

Без входа подтверждены пассажирские множители спроса. Источник рублёвой надбавки водителя не подтверждён, уведомления о +200 ₽ пока не работают с реальными данными. Авторизация, батарея, длительный мониторинг и сравнение с Яндекс Про требуют проверки. Канал обновлений из закрытого GitHub без авторизации пока недоступен.
