Радар Pro 0.1.6-alpha — новый дизайн по согласованному изображению.

Полноэкранная тёмная карта, компактные кнопки справа, нижняя карточка точки. Список точек с разделителями и переключателями. Настройки в округлых блоках, навигация с иконками. Компактный виджет с жёлтой обводкой, крупным значением и раскрываемыми кнопками Настройки/Закрыть.

Точки, тарифы, уведомления, параметры и положение виджета сохраняются при обновлении. Пакет dev.raf.radar, versionCode 7, Android 9+. Устанавливать поверх старой версии; приложение не удалять.

Цветные метки отображают данные конкретных точек. Рублёвые значения остаются расчётными; совпадение с Яндекс Про не подтверждено.
