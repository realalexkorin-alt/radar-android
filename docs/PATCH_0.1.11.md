# Радар Pro 0.1.11-alpha: проверка обновления

Пакет `dev.raf.radar`, versionCode 12, Android 9+. База изменений — актуальная 0.1.10. Новые настройки виджета и независимые тарифы точек сохранены.

## Что выяснено

Сообщение «Неверный пакет APK» в старом коде объединяло две разные причины: системный `getPackageArchiveInfo` вернул `null` либо имя пакета отличается. SHA-256 проверяется до этого места, то есть такое сообщение возникает после скачивания файла. Настоящий релиз удалось скачать и прочитать в эмуляторах Android 11, 13 и 15; специфическая причина на телефоне пользователя не воспроизведена. Модель телефона и точная версия Android не получены.

## Исправление

Убрана зависимость обновления от системного разбора архива через `getPackageArchiveInfo`. Используется `com.android.tools.build:apksig:8.7.3`: сначала криптографически проверяется APK для версии Android устройства, затем из подписанного бинарного манифеста читаются имя пакета, versionCode и минимальная версия Android. Набор сертификатов должен совпадать с сертификатами установленного приложения. SHA-256, запрет другого пакета и понижения версии сохранены. Проверки подписи не обходятся.

Ошибка теперь остаётся в диалоге с кнопкой «Скопировать», этапом сбоя и версиями приложения/Android. Несовпадение имени пакета сообщает оба имени вместо общего «Неверный пакет APK».

## Проверки

Локально: 49 модульных тестов без ошибок; `lintRelease` без ошибок (10 предупреждений), сборка release/debug, Android-тестов и отдельного драйвера установки успешны.

Финальный CI: https://github.com/realalexkorin-alt/radar-android/actions/runs/39358840086 . Коммит: `df4adc38d06cfb4f2de3e6ccfa16b9b3da749083`. Все задания успешны.

Тест настоящего релиза 0.1.10 скачивает его с GitHub, проверяет закреплённый SHA-256, имя, versionCode и сертификат. Другой тест удаляет подпись при перепаковке и требует отказа.

Для системной установки используется отдельный тестовый процесс `upgradecheck`, который не прекращается при обновлении Радара. В приватный кеш сборки с versionCode 12 помещается подписанная той же тестовой подписью сборка с versionCode 13. Сам Радар повторно проверяет кешированный APK и открывает системный установщик; драйвер подтверждает установку и проверяет смену версии. Сохранность настроек и точек проверяется отдельно. Тестовый драйвер не входит в распространяемый APK Радара.

## Установка на телефон

Если установленная версия отказывается готовить APK с сообщением «Неверный пакет APK», этот патч нужно один раз скачать и установить вручную поверх приложения. Приложение не удалять. Код старой установленной версии не заменяется до установки нового APK. Эмуляторы не подтверждают поведение конкретной оболочки телефона; после установки необходима проверка пользователем.
