# Радар Pro 0.1.13 — Эконом и уровни надбавки

- Только Эконом: сохранённые точки, имена, координаты, пороги уведомлений и положение виджета сохраняются.
- Цена: 0–99 белая, 100–199 синяя, 200–299 фиолетовая, 300–399 золотая, от 400 алая («Катастрофа»).
- Виджет показывает только цену, подстраивается под цифры и шрифт, плавно перемещается сразу при движении пальца. Свечение усиливается с уровнем; у Катастрофы — алый импульс и движущийся блик. Тап открывает приложение, удержание без движения — настройки.
- Логотип пользователя в шапке; PRO включает мониторинг и виджет, повторное нажатие выключает оба. Зелёный статус и звук появляются после запуска службы.
- Настройки сокращены: работа приложения, раскрывающиеся параметры виджета, общий переключатель звуков, обновления внизу. Тёмная тема постоянная.
- У новой карточки — «Сохранить», у сохранённой — «Удалить». Тап по карте вне карточки закрывает её без сохранения.
- Событийные звуки: ответ проверки обновлений (два варианта), загрузка, подготовка установки, открытие/сохранение новой точки, удаление, успешный запуск. Отключаются общим переключателем; автоматическая проверка обновлений не озвучивается.

## Область проверки

L2: цвета, оформление, настройки, жесты и карточки. L3: миграция тарифов с сохранением данных, запуск/остановка службы, озвучка этапов обновления. Проверки связаны с этими изменениями: выбранные unit-классы, EconomyPatchTest, UpdateArchiveTest, StartupSoundTest, входные разрешения, обновление с сохранением данных и системный установщик на Android 11 (узкий экран) и Android 15. Старые сценарии выбора нескольких тарифов и прежнего меню виджета больше не соответствуют продукту; они не входят в профиль economy. Полный исторический набор доступен вручную.
