# Проверка патча 0.1.2-alpha

19 октября 2026. Пакет dev.raf.radar, versionCode 3, Android 9+.

Добавлен независимый расчёт разницы между текущей пассажирской ценой и базой тарифной зоны; округление до 10 ₽, минимум 0. База — снимок публичного tariff230.json на 19.10.2026, 686 зон, включена в APK. Для неизвестной/нулевой базы и валют кроме RUB рублёвая оценка не выдаётся. Множитель спроса сохраняется отдельно. Определение зоны кэшируется на час, при смещении более 0.002 градуса по любой оси запрос повторяется.
