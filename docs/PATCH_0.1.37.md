# 0.1.37 · виджет без плюса

В виджете надбавка отображается без ведущего «+». Возможность возвращения знака сохранена в коде через widgetShowPlus (по умолчанию false), без новой строки настроек. Карта и списки сохраняют прежний формат.

Круг рассчитан на «999», базовый диаметр уменьшен с 88 до 80dp (фактический размер учитывает метрики шрифта и подпись). При смене количества цифр диаметр постоянен. Размер, шрифт, прозрачность и опциональное время по центру сохранены.

Проверка: сборка release, lint и один целевой тест API35: цена действительно видна на снимке, знак отсутствует, размеры стабильны, опциональный плюс работает, ручной масштаб сохранён.
