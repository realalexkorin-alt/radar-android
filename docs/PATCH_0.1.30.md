# 0.1.30-alpha · автоматическая диагностика

## Изменения
- Структурированный журнал последних 60 минут: запросы надбавок, HTTP-коды, длительность запросов, причины и сроки пауз, результаты GPS, служба мониторинга, аккаунт/друзья, обновление приложения, ошибки интерфейса и необработанные Java-исключения.
- Контроль отсутствия успешной надбавки более max(5 минут, 2 интервала + 1 минута), остановленной службы, отсутствия свежего GPS и остановки очереди более 90 секунд. Контроль выполняется раз в минуту, пока процесс может выполняться.
- При ошибке сохраняется снимок журнала, автоматически отправляемый авторизованным аккаунтом на /api/diagnostics. Повторные ошибки записываются в журнал, новые снимки объединяются в окно 15 минут. Отправка отдельным потоком не блокирует очередь надбавок.
- После потери сети очередь сохраняется на диске; повторная отправка с паузой 2–60 минут. До 8 отчётов локально, до 7 дней ожидания. Журнал ограничен 1200 событиями/250 тыс. символов.
- Сервер хранит до 50 отчётов пользователя, не более 7 дней. Просроченные отчёты сразу исключаются из чтения, физическая очистка pg_cron раз в 10 минут.
- «Дополнительно → Диагностика»: состояние мониторинга, последняя ошибка и отправка; копирование и ручная отправка отчёта.
- Переключатель «Виджет поверх приложений» перенесён в раздел «Виджет».
- Время обновления сохранённых точек карты включается отдельно в «Дополнительно», по умолчанию выключено. Возраст координат пользователей убран с карты и списка друзей; статус «Был в сети» сохранён.

## Данные и доступ
Сохраняются только заранее заданные поля: версия/модель/SDK, коды событий, HTTP, длительность, возраст данных и состояние разрешений/сети. Тексты исключений, ответы API, пароли, cookie, сессии, коды восстановления, имена и координаты не собираются. Стек ограничен восемью строками кода приложения. Сервер повторно фильтрует поля.

POST принимает только действующую сессию аккаунта, лимит 4 запроса/минуту. GET доступен только с отдельным секретом чтения; сессия пользователя права чтения не даёт. APK не содержит секрет чтения.

Секрет чтения воспроизводится локально из существующего защищённого архива подписи: SHA256(p12 + NUL + stripped password), затем HMAC-SHA256 с сообщением `radar-diagnostics-reader-v1`. В серверном окружении `RADAR_DIAGNOSTICS_READER_HASH` находится только SHA256 этого секрета. Не публиковать архив, пароль или результат HMAC.

Чтение: `python scripts/read-diagnostics.py --private-directory /protected/signing-directory --user-id 1 --limit 5`. Папка содержит `radar-release.p12` и `password.txt`. Не передавать секрет в командной строке и не сохранять отчёты в публичный репозиторий.

## Границы
Автоотправка требует авторизованного аккаунта, сети и возможности выполнения процесса. Принудительное завершение Android не позволяет выполнить код отправки в момент остановки; сохранённый отчёт уйдёт после запуска. На Android 11+ дополнительно читается причина предыдущего завершения (ANR/crash/нехватка памяти), без системного текста трассировки. При аварии запись выполняется до стандартного обработчика; OOM/поломка накопителя не позволяют гарантировать запись.

Патч добавляет наблюдаемость. Он не отменяет защитные паузы API и не доказывает причину конкретного часового сбоя без отчёта с телефона. Интервалы запросов и GPS не меняются.
