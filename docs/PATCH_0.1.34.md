# 0.1.34 · привязка меток и области

Сохранённая метка имеет указатель и точку привязки к фактическим координатам. Перетаскивание плашки меняет только локальное экранное смещение (до180dp), сохранённое после перезапуска; отмена жеста возвращает прежнее положение. Тап открывает редактор, карта за пределами плашки продолжает получать жесты. Перенос координат выполняется в существующем редакторе отдельно и сбрасывает старую надбавку/направление; серверная история не меняется.

При «Прогнозирование» видны мягкие географические области радиусом1000м, рассчитанные по сфере, цвет соответствует динамике, непрозрачность до30%. Близкие сохранённые точки не создают дублирующие круги. Центр не зависит от перетаскивания подписи; радиус не фиксирован в пикселях и меняется с масштабом. Пока нет проверенного прогноза, общие дополнительные метки всем пользователям не публикуются; 0% остаётся заглушкой.

Проверки: геодезический радиус на разных широтах и у линии дат; API35-проверка перетаскивания без изменения координат и очистки цены после переноса. Release и lint. Содержит сбор статистики0.1.33.
