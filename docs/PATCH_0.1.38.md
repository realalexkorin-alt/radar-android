# 0.1.38 · минутная очередь точек

Все сохранённые точки участвуют в обновлении при включённом общем мониторинге, включая фон и старые точки с отключённым переключателем. Частота больше не зависит от просмотра карты, уведомлений, виджета и прежнего interval. Вместо индивидуального выключателя в списке — настройка точки. Общая кнопка остановки мониторинга сохранена.

Одна последовательная очередь без параллельных запросов. Сначала собственная геопозиция при свежем GPS, затем ближайшие сроки; адаптивный промежуток зависит от числа точек и резерва для собственной надбавки. Сохранённая точка получает следующий срок через60с; запуск допускается до15с раньше, чтобы покрыть задержки таймера и запросов. Рабочий цикл около45–60с при доступном сервисе и достаточной пропускной способности. Проверка очереди каждую секунду после завершения предыдущей работы. Для собственной надбавки цель10с, очередь может увеличить интервал при нагрузке. GPS-провайдеры не изменены.

Просмотр карты и изменения настроек больше не обнуляют сроки всей очереди. Часы планировщика — монотонные elapsedRealtime; время статистики остаётся календарным. Старые HTTP401/403/429 паузы15мин и сетевой backoff сохранены. Минутная свежесть не гарантируется при потере сети, медленном API, ограничениях сервера, большом числе точек, остановке процесса или Android Doze. Параллельные запросы и обход ограничений не добавлены.

Статистика фиксированных точек сохраняется по прежнему правилу: одна успешная выборка на точку не чаще300000мс, первая пригодная после этого срока. Частые обновления карты не создают минутных строк в базе. Передача из устойчивой очереди остаётся фоновой с повторами. Сервер, погода и схема данных не меняются.

Проверки: симуляция часа для5 и10 точек с ответом2с и паузой1с; все сохранённые точки повторно опрашиваются не позднее60с, без голодания. Добавление/удаление, отсутствие GPS, пауза API и отсутствие всплеска запросов; миграция старого выключателя; минутные показания дают только5-минутные образцы. Только PollPlannerTest/ObservationQueueTest, release и lint; полный прогон приложения не требуется.
