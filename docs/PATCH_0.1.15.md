# Радар PRO 0.1.15 — пользователи на карте

Пакет dev.raf.radar, versionCode 16. База main 52b4a811.

## Поведение
- Собственная GPS-точка — золотой круг с рамкой и свечением; устаревший GPS приглушён.
- Виджет всегда использует только свежую рублёвую надбавку Эконома текущей GPS-геолокации. При отсутствии данных — «—», без множителей.
- Дополнительно → Делиться местоположением, по умолчанию выключено. Передача только при запущенном PRO и свежем разрешённом GPS.
- Другие пользователи с включённой передачей — фиолетовые точки. Просмотр не требует передачи своего положения.
- Отправка и опрос карты раз в 30 секунд, просмотр только при открытой карте. Фоновые запросы надбавок используют прежнюю очередь и ограничения.
- Сервер Vercel Functions + существующий Neon PostgreSQL проекта Авито хранит только текущую точку; срок координат до 120 секунд с учётом возраста GPS. Истории перемещений нет. После отключения — DELETE, при потере сети — срок действия и автоочистка.
- Случайный 256-битный секрет установки остаётся на устройстве, сервер выводит из него публичный SHA-256 ID. Последовательные ревизии не позволяют старому запросу восстановить удалённую точку.
- Просмотр ограничен 200 точками из 1000 последних активных пользователей. Для первой небольшой аудитории; перед масштабированием требуется пространственный индекс.

## Хранение и эксплуатация
Проект Vercel radar-presence, регион iad1, рядом с существующей базой Neon в us-east-1. По указанию владельца от 20.10.2026 используется база Авито neon-amethyst-blanket на существующем Free-плане. DATABASE_URL хранится только на сервере и не входит в APK. Схема radar_presence изолирована; таблицы Авито не изменяются. Детали установки pg_cron, автоматической очистки и остановки расписания при отсутствии точек — backend/README.md. Планировщик проверен на реальной базе без API-трафика; рабочая координата очищается автоматически, пустое расписание останавливается. Резервные версии Neon имеют отдельную политику хранения (наблюдалось 6 часов).

Проверено: CI 39418338775 — сборка, lint, серверный контракт, Android 11/15, миграция и системное обновление; золотая/фиолетовая точки подтверждены снимком. APK 0.1.15-alpha (16) подписан прежним сертификатом. PostgreSQL: 4 контрактных теста и реальный тест двух клиентов прошли; проверены изолированное удаление, атомарное отклонение старой ревизии, автоочистка после 121 секунды без трафика и остановка пустого расписания. Временный ключ ограничен только проектом базы и отозван после настройки; проверка старого ключа вернула 401.
