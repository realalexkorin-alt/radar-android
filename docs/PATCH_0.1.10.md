# Радар Pro 0.1.10 — независимые тарифы виджета и точек

- В настройках приложения отдельный блок «Тарифы виджета». Выбранные тарифы располагаются вертикально: Эконом, Комфорт, Комфорт+, затем остальные.
- Каждая точка на карте отображает только тарифы, выбранные в настройках именно этой точки.
- Общий фильтр карты удалён. Настройки виджета и точек не влияют друг на друга.
- Местоположение виджета выбирается отдельно. Сохранение точки не переключает источник виджета.
- При обновлении сохраняется прежний набор тарифов виджета, после переноса он хранится независимо от точки. Геопозиция, точки, пороги уведомлений, размер и положение виджета сохраняются.
- Изменения применяются сразу; отсутствующие данные обозначаются «—» до получения ответа. Лимиты запросов и паузы сервиса сохранены.

Android 9+, versionCode 11. Постоянная подпись проекта, установка поверх предыдущей версии. Значения в рублях расчётные.
