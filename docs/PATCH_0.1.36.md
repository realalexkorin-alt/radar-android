# 0.1.36 · круглый виджет

Круглый фон, цена по центру. Размер определяется по эталону «+999» и выбранным пользователем масштабам виджета/шрифта, не по текущему значению. Одно-, двух- и трёхзначная надбавка, ноль, отсутствие данных и время обновления не меняют диаметр. Ползунки размера виджета и шрифта сохранены; прозрачность также сохранена. При экстремальных размерах круг ограничен экраном, текст подгоняется внутрь; значения длиннее трёх цифр уменьшают только шрифт значения, не размер круга. Слева/справа базовый отступ10dp, цена и подпись центрированы.

Опциональное время обновления — число прошедших секунд без слов/единиц, белое полупрозрачное, под надбавкой. Отсчитывается от последнего успешного ответа; ошибка не сбрасывает возраст. Для доступности полное описание остаётся в contentDescription. Диаметр и центр цены не зависят от включения подписи. Перемещение, тап и удержание виджета сохранены.

Целевой WidgetAgeTest/API35: окружность и центры, вхождение«+999», одинаковые размеры для0/9/50/999/1250, переключение времени, ручное масштабирование и пересоздание после ошибки. Release и lint. Данные/сервер/карта не меняются.
