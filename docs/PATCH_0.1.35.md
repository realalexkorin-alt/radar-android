# 0.1.35 · карта без радиусов и перетаскивания

Полностью убрана отрисовка километровых областей прогнозирования. Удалён обработчик перетаскивания плашек. Сохранённая метка всегда закреплена над координатой с коротким указателем; смещения, оставшиеся после0.1.34, больше не используются. Жесты карты и открытие редактора по нажатию сохраняются. Сбор статистики, серверные области1км, стрелки и0% сохраняются.

Целевой MapAnchorTest/API35 проверяет фиксированную привязку, игнорирование старых смещений, отсутствие перехвата жеста и неизменность координат. Release и lint. Изменений сервера нет.

Сохранённые точки сейчас локальные: автоматического копирования другим пользователям нет. История статистики не является каталогом сохранённых точек. Предлагаемый отдельный следующий патч: кнопка «Копировать точки друзей», выбор подтверждённого друга, доступные для копирования сохранённые точки, выбор и импорт с устранением дублей; собственные ID и настройки у копий. Сначала понадобится отдельная серверная синхронизация каталога и разрешение владельца делиться им. Личная GPS-геопозиция не включается в копирование. Это предложение, не реализованная функция0.1.35.
