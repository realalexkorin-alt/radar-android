# Радар Pro 0.1.6-alpha — дизайн по референсу

Основание: изображение «Презентация приложения Радар Pro.png», предоставленное пользователем 19 октября 2026.

- Полноэкранная карта, плавающие кнопки поиска/слоёв/геопозиции; нижняя карточка с координатами, значением, адресом и парой кнопок Сохранить/Отменить.
- Тёмный векторный стиль Shortbread с отдельными цветами дорог, воды, зданий и подписей. OpenStreetMap attribution сохранён. Указатели и мягкое свечение отображаются только для конкретных сохранённых точек; широкие зоны спроса и их границы не выдумываются.
- Точки: заголовок, жёлтая кнопка плюс, цветные индикаторы, название/адрес и переключатели; разделители вместо отдельных карточек. Настройки динамической геопозиции доступны в настройках приложения.
- Настройки: округлые блоки Виджет, Тарифы, Обновление. Размеры выбираются из списка, прозрачность регулируется ползунком, тарифы и автоматическая проверка — переключателями.
- Нижняя навигация: рисованные иконки и подписи; активные элементы жёлтые, без залитых кнопок.
- Виджет: чёрный фон с жёлтой рамкой, название тарифа над крупным значением, стрелка справа; в раскрытом виде отдельные кнопки Настройки/Закрыть. Жесты, масштаб и позиция сохраняются.
- Дополнительные настройки уведомлений, перемещения/переименования/удаления точки, авторизации и разрешений сохранены в дополнительных экранах.

Package dev.raf.radar, versionCode 7. Используется прежний ключ подписи. Прямой переход с 0.1.5 без удаления приложения.

Карта использует https://vector.openstreetmap.org/shortbread_v1/tilejson.json с нативным кэшированием MapLibre. Идентификатор HTTP SDK включает имя приложения. Нет предзагрузки/скрейпинга карт. Источник хранится в настройке vectorTileJson и может быть изменён без правки стиля.

Проверки и публикация выполняются после функционального CI и визуального просмотра реальных снимков эмулятора. Данные референсных снимков создаются только в androidTest. Рублёвые значения рабочего приложения остаются расчётными.
