# Радар

Текущая версия: 0.1.39-alpha. Android 9+.

Кнопка «Проверить обновления» закреплена за репозиторием проекта, ввод адреса не требуется. Если новой версии нет, приложение сообщает об этом. Загрузка показывает прогресс; после разрешения установки в Android уже скачанный APK устанавливается без повторного скачивания. Контрольная сумма, версия, пакет и подпись проверяются перед установкой.

При входе проверяются точная геопозиция, уведомления, показ поверх других приложений и возможность установки обновлений. Отсутствующий доступ запрашивается у Android либо открывается соответствующий системный экран. После возврата доступ перепроверяется. Мониторинг не запускается без точной геопозиции и уведомлений; закрытые специальные возможности не используются. Доступ к общим файлам, контактам, микрофону и фоновая геолокация не запрашиваются.

Виджет всегда показывает свежую надбавку Эконома текущей GPS-геолокации в рублях. При отсутствии свежего GPS или значения RUB показывает «—». Выбора сохранённой точки для виджета нет. На карте собственная точка выделена золотой рамкой и свечением. В дополнительных настройках есть «Делиться местоположением», по умолчанию выключено; передача работает только при запущенном PRO и свежем GPS. Другие пользователи, включившие передачу, отображаются фиолетовыми точками. Просмотр не требует передачи своего местоположения.

При включённом мониторинге все сохранённые точки обновляются общей последовательной очередью с целевым циклом до минуты, включая фон. Для собственной геопозиции цель — 10 секунд с учётом нагрузки. Паузы при ограничениях API и сетевых ошибках сохраняются. Статистика фиксированных точек записывается не чаще одного раза в пять минут. Подробности и ограничения — docs/PATCH_0.1.38.md.

Расчётная надбавка ₽ = текущая пассажирская цена API − базовая цена тарифной зоны, с округлением до 10 ₽ и минимумом 0. Совпадение с надбавкой в Яндекс Про не подтверждено. Для неизвестной базы приложение показывает «—»; множители не отображаются. Таблица баз включена в APK; источник: https://github.com/vitg8/radar_update/releases/download/v1/tariff230.json, снимок 19.10.2026. Обновляется выпуском нового APK. Приложение не обращается к серверу стороннего радара.

Уведомления: порог каждой точки, пауза 30 минут, досрочный повтор при росте на 50 ₽. Динамическая точка следует за пользователем.

Обновление: Настройки → Проверить обновления. Для версии 0.1.1 укажите `realalexkorin-alt/radar-android` в поле GitHub. После загрузки подтверждается системная установка поверх старой версии. Подпись и данные сохраняются. Публикация исходников сама по себе не устанавливает обновление: нужен опубликованный релиз с `radar.apk`.

Сборка и проверки: `./gradlew :app:testDebugUnitTest :app:lintRelease :app:assembleRelease`. Постоянный ключ задаётся через переменные RADAR_KEYSTORE, RADAR_STORE_PASSWORD, RADAR_KEY_ALIAS, RADAR_KEY_PASSWORD; приватные ключи в репозитории не хранятся. Для патча 0.1.15 GitHub Actions проверяет Android 11 и 15, сохранение данных при переходе между версиями и установку через системный установщик. Модуль `upgradecheck` — отдельный тестовый драйвер, он не входит в APK Радара.

В 0.1.11 чтение APK заменено на библиотеку Android apksig: проверяются криптографическая подпись, подписанный манифест, сертификат установленного приложения и SHA-256. Если старый установленный Радар выдаёт «Неверный пакет APK», один раз установите исправленный APK вручную поверх приложения. Ошибки теперь можно скопировать из диалога.


Сервер геолокаций: `backend/`, эксплуатация и сроки очистки — `backend/README.md`. Используется существующая бесплатная Neon-база проекта Авито по указанию владельца. В приложении нет истории перемещений. Рабочая координата удаляется после отключения передачи либо автоматически не позднее 120 секунд; резервные версии базы подчиняются настройкам хранения Neon.

Темы: Настройки → Дополнительно → Темы. Стандартная сохраняет прежнее оформление и звуки; Lineage 2 добавляет пергаментную карту, металлические панели, кристаллы и векторную анимированную эмблему. Выбор применяется без перезапуска мониторинга и сохраняется после закрытия приложения. В Lineage 2 звуки отключены до отдельного патча; настройка звука стандартной темы сохраняется. См. docs/PATCH_0.1.39.md.
