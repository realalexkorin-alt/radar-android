# Радар Android

Собственное Android-приложение: карта MapLibre, сохранённые точки, динамическая геопозиция, плавающий виджет, мониторинг и механизм обновлений из GitHub Releases.

## Статус: 0.1.1-alpha

**Это исследовательская альфа, не готовый сервис рублёвых надбавок Яндекс Про.** Анонимный запрос к пассажирскому сервису возвращает тарифы, цены и `paid_options.value` — множитель спроса. Он не является надбавкой водителя в рублях. Приложение показывает `×`, а неизвестное значение как `—`; цену поездки не подставляет вместо надбавки. Правила уведомлений в рублях реализованы, но без подтверждённого источника RUB не срабатывают.

Нет рекламы, аналитики, чужого backend и экспорта сессий. Старый APK в репозиторий не включён. Приложение не принимает, не отклоняет заказы и не меняет приоритет водителя.

## Сборка

Android 9+, JDK 17, Android SDK Platform 35.

```sh
./gradlew testDebugUnitTest lintDebug assembleDebug
```

Debug APK: `app/build/outputs/apk/debug/app-debug.apk`. Подписанный выпуск:

```sh
export RADAR_KEYSTORE=/private/path/radar-release.p12
export RADAR_STORE_PASSWORD='read securely from your local secret store'
export RADAR_KEY_ALIAS=radar
export RADAR_KEY_PASSWORD="$RADAR_STORE_PASSWORD"
./gradlew testDebugUnitTest lintRelease assembleRelease
```

Не коммитьте ключ, пароль, cookies и токены. Все будущие обновления устанавливаются только с тем же ключом подписи и увеличенным `versionCode`.

## Использование

1. Открыть приложение и разрешить геопозицию при запуске мониторинга.
2. Добавлять точки удержанием карты либо вводом адреса/координат. Поиск адресов зависит от наличия Android Geocoder; координаты работают без него.
3. Нажать карточку для выбора тарифов и правил уведомлений. `Моя геопозиция` следует за GPS; старые и неточные координаты не опрашиваются.
4. Для виджета разрешить показ поверх приложений. Выбрать точку нажатием карточки, затем включить виджет. Положение сохраняется; заголовок перемещает и сворачивает. Размер зависит от содержимого.
5. В настройках — тема, прозрачность, масштаб, размер текста, фиксация виджета и интервал.
6. Остановить мониторинг кнопкой в приложении или уведомлении.

Минимальный глобальный разрыв запросов — 15 секунд. Интервал точки по умолчанию 120 секунд. 30 точек требуют минимум 7,5 минуты на круг, плюс сеть. Ручное обновление не отменяет общую паузу. При 401/403/429 — пауза 15 минут; другие ошибки — увеличение паузы. Смена endpoint и маскировка клиента не применяются.

Уведомления выключены по умолчанию. Для каждой точки можно выбрать порог. Таймер общий для тарифов одной точки: первое достижение сразу; затем через 30 минут либо после роста на 50 ₽ относительно последней отправленной суммы. Учитываются только свежие, проверенные рублёвые данные. В текущем провайдере таких данных нет.

## Карта

MapLibre Native 11.8.0; подложка OpenStreetMap raster для альфы с атрибуцией. Это ещё не полноценная векторная тема. Перед распространением выбрать постоянного провайдера, проверить его условия, лимиты и доступность. Нет offline-загрузки и массового скачивания тайлов.

## Авторизация

Основные исследования выполнены без входа. Экспериментальный WebView открывает сайт Яндекс Такси; он не извлекает пароль, не имеет JS-моста, не отключает TLS. Cookies остаются в sandbox приложения; резервное копирование выключено. Совместимость cookies и серверных запросов не подтверждена. Нет обхода CAPTCHA, ограничений аккаунтов или сервисов.

## GitHub и обновления

В настройках указать `owner/repository`. Проверка читает последний опубликованный GitHub Release; ожидается asset `radar.apk` с GitHub `digest: sha256:...`. Перед установкой проверяются SHA-256, package name, более высокий versionCode и тот же signing certificate. Android запрашивает разрешение на установку.

**Закрытый репозиторий не является публичным каналом обновления.** В APK нет GitHub PAT. Для обновлений без GitHub-входа нужен отдельно согласованный публичный репозиторий выпусков. Возможность проверять и скачивать обновления с реального канала ещё не проверена end-to-end.

Workflow `Android checks` строит debug APK и отчёты. `Signed release` требует secrets `RADAR_KEYSTORE_B64`, `RADAR_STORE_PASSWORD` в environment `release`, создаёт черновик релиза. Секреты пока не настроены. Публикация релиза выполняется после проверки; платные ресурсы не создаются.

## Проверки

См. `docs/TEST_REPORT.md`. Наличие кода не означает, что функция подтверждена на устройстве. Реальную надбавку водителя, сессию, батарею и ограничения производителя телефона необходимо проверить отдельно.
