# Радар

Текущая версия: 0.1.4-alpha. Android 9+.

Кнопка «Проверить обновления» закреплена за репозиторием проекта, ввод адреса не требуется. Если новой версии нет, приложение сообщает об этом. Загрузка показывает прогресс; после разрешения установки в Android уже скачанный APK устанавливается без повторного скачивания. Контрольная сумма, версия, пакет и подпись проверяются перед установкой.

При входе проверяются точная геопозиция, уведомления, показ поверх других приложений и возможность установки обновлений. Отсутствующий доступ запрашивается у Android либо открывается соответствующий системный экран. После возврата доступ перепроверяется. Мониторинг не запускается без точной геопозиции и уведомлений; закрытые специальные возможности не используются. Доступ к общим файлам, контактам, микрофону и фоновая геолокация не запрашиваются.

Компактный виджет: название точки, тарифы, суммы, крестик. Нажатие открывает приложение; удержание без перемещения открывает настройки после отпускания пальца; удержание и движение переносит виджет. Положение сохраняется, устаревшие данные приглушаются.

Моя геопозиция обновляется первой. Сохранённые точки запрашиваются только при открытой карте со списком, для виджета или включённых уведомлений. Видимость экрана отслеживается с коротким сроком действия, поэтому после закрытия или завершения процесса лишние запросы прекращаются. Общая пауза между запросами 15 секунд и паузы при ошибках сохраняются.

Расчётная надбавка ₽ = текущая пассажирская цена API − базовая цена тарифной зоны, с округлением до 10 ₽ и минимумом 0. Совпадение с надбавкой в Яндекс Про не подтверждено. Для неизвестной базы приложение показывает множитель при его наличии. Таблица баз включена в APK; источник: https://github.com/vitg8/radar_update/releases/download/v1/tariff230.json, снимок 19.10.2026. Обновляется выпуском нового APK. Приложение не обращается к серверу стороннего радара.

Уведомления: порог каждой точки, пауза 30 минут, досрочный повтор при росте на 50 ₽. Динамическая точка следует за пользователем.

Обновление: Настройки → Проверить обновления. Для версии 0.1.1 укажите `realalexkorin-alt/radar-android` в поле GitHub. После загрузки подтверждается системная установка поверх старой версии. Подпись и данные сохраняются. Публикация исходников сама по себе не устанавливает обновление: нужен опубликованный релиз с `radar.apk`.

Сборка и проверки: `./gradlew testDebugUnitTest lintRelease assembleRelease`. Постоянный ключ задаётся через переменные RADAR_KEYSTORE, RADAR_STORE_PASSWORD, RADAR_KEY_ALIAS, RADAR_KEY_PASSWORD; приватные ключи в репозитории не хранятся. GitHub Actions выполняет модульные и Android 11 UI-тесты. Подписанные релизы создаются через workflow Signed release после успешных проверок.
